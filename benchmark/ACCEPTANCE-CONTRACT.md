# WAVE-01 ACCEPTANCE CONTRACT

## Mechanical gate
- 18/18 valid executions after re-running only mechanically invalid runs.

## Fatal gate for PAR candidate
- Lane C: 0 evidence-integrity fatals.
- CASE-05: no definitive authenticated IA from marketing-only evidence.
- CASE-04: no confident pre-answer freeze before the decisive operating-axis fact.
- CASE-06: must identify the upstream Team/context distinction to receive a case PASS.

## Capability gate

### Against baseline A
Lane C must show a material advantage in consequential-decision + epistemic behavior on at least 4/6 cases.

### Against strong comparator B
Lane C must show a material advantage on at least 3/6 cases.

"Material advantage" means the blind adjudicator prefers C on BOTH:
- consequential decision discovery; and
- epistemic behavior (questions/evidence/uncertainty/reframe as applicable).

## Case-critical gate
Lane C should pass these targeted behaviors:

- CASE-01: overturn or strongly revisit weak dashboard incumbent using explicit recurring-job evidence.
- CASE-02: preserve sound dense-table incumbent; avoid novelty bias.
- CASE-03: identify competing intent/information architecture, not generic CRO list.
- CASE-04: obtain decisive operating-axis evidence with a high-value question before firm recommendation.
- CASE-05: refuse false authenticated-IA certainty.
- CASE-06: REFRAME placement into Team-as-context vs Team-administration.

Minimum: 5/6 targeted case behaviors PASS.
CASE-05 and CASE-06 are mandatory.

## Authority/content gate
At least 4/6 Lane C outputs contain one judgement the blind adjudicator marks as:
`PUBLICLY_DISCUSSION_WORTHY = YES`.

## Publish verdicts

### PASS — PUBLISH V0
All mandatory gates pass.

### CONDITIONAL — ONE FOCUSED V0.1 REVISION
No core thesis failure, but one or two local defects block publish.
Only one focused revision cycle is authorized.
Re-run all 6 cases after revision.

### FAIL — KILL / RADICALLY NARROW
Any of:
- evidence-sufficiency thesis fails;
- reframe thesis fails;
- no material delta vs comparator B after one revision;
- output repeatedly degenerates into generic UX audit;
- >1 core epistemic fatal in Lane C.

Do not rescue the project through an open-ended methodology program.
