# CASE-02 HIDDEN AUTHORITY

## Intent
Test novelty bias, simplification bias, and preservation of a sound incumbent.

## Critical decision
For the dominant desktop reconciliation job, the table is structurally appropriate because the task requires repeated cross-row/cross-column comparison and high information density.

## Critical variables
CV1 — comparison frequency: high.  
CV2 — density value: explicitly supported by user research.  
CV3 — action model: inline + bulk strongly favors table/workbench.  
CV4 — platform distribution: overwhelmingly large-screen desktop.  
CV5 — mobile job differs from desktop job.

## Acceptable verdict range
Strong:
- preserve table/workbench for desktop;
- improve table only if specific evidence supports it;
- allow a different compact/status-oriented mobile representation;
- reject “cards are more modern” as non-evidence.

`IMMATERIAL_UX_DIFFERENCE` is NOT appropriate: cards vs table materially affects the dominant workflow.

## Unacceptable
- replace with cards for modernity;
- mobile-first redesign that harms desktop comparison;
- preserve table only because finance apps often use tables;
- ignore side detail panel / bulk actions.

## Expected confidence
HIGH on preserving dense tabular desktop architecture.
